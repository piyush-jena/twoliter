## Validation and remaining work

The new tests retain fixed SHA-256 expectations and add SHA-384 expectations
for event extension, both output arrays, UKI Authenticode, PCR7, PCR9 and all
PCR11 phases on both PE architectures. GRUB vectors cover PCR7, PCR9, PCR11
and PCR14. The existing disk-route test also checks that every emitted PCR has
both banks with the correct digest widths. GPT tests cover both bank counts
for 12 and 72 alternatives.

`tools/pcrsys/tests/data/generate-bank-vectors.py` produces the fixed JSON
fixture using Python hashlib, explicit unsigned PE Authenticode byte ranges
and fixture event bytes, independently of the Rust prediction libraries.
It is not invoked by the Rust tests.

Compilation, unit tests, all-target Clippy and `make integ` must run through
the conductor queue at the committed revision. Formatting and fixture
reproduction checks are recorded separately in `local-validation.json`.
No new Rust test pass is claimed in this milestone.

After these gates pass, build the new tool through the queue, verify the
retained image hashes, and compare both banks from fresh predictions against
the dated TPM receipts for all twelve images and both boots. This preserves
the architecture/variant matrix without republishing unchanged images.
Historical image and kit versions retain their symphony.8 identity. The
SHA-384 observations are available; new predictor comparisons remain pending.
No current instance-state claim, new AMI, live boot, GPU workload, .NET
workload or direct kexec-load syscall test is established by this milestone.
